# 進化狂奔 Evo Runner

從三疊紀的蛋殼裡跑出來，一路跑過兩億五千萬年的像素恐龍跑酷遊戲。分數越高，恐龍會進化成新的型態並解鎖新能力。

**線上遊玩：** https://stwater20.github.io/evo-runner/

## 進化路線

| 分數 | 型態 | 年代 | 解鎖能力 |
|---|---|---|---|
| 0 | 破殼幼龍 | 三疊紀 | 跳躍 |
| 250 | 迅掠龍 | 侏羅紀 | 二段跳 |
| 600 | 羽冠龍 | 白堊紀 | 滑翔（下落時按住跳躍） |
| 1100 | 始祖翼 | 白堊紀末 | 羽盾（每 8 秒擋一次撞擊），隕石開始墜落 |

## 操作

- **電腦**：`空白鍵` / `↑` 跳躍，空中再按為二段跳；下落時按住為滑翔；`↓` 蹲下，空中按住加速落地
- **手機**：點畫面右側跳躍、按住滑翔；按住左側蹲下

## 技術

單一 `index.html`，純 Canvas 2D，不需要建置工具。角色與障礙物都是程式繪製的像素圖，頂端時間軸使用國際地層年代表（ICS）的年代配色。

本機遊玩：直接用瀏覽器開啟 `index.html`。
